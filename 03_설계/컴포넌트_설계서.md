## 1. 설계 철학

### 1.1 컴포넌트 분류 (Atomic Design 변형)

| 계층 | 위치 | 책임 | 예시 |
|---|---|---|---|
| **UI Primitives** | `components/ui/` | 원자 컴포넌트 (재사용) | `Button`, `Input`, `Modal` |
| **Composite** | `components/` | 여러 primitive 조합 | `NoteCard`, `FolderTree` |
| **Feature** | `features/<domain>/` | 도메인 로직 + 상태 결합 | `TiptapEditor`, `GraphCanvas` |
| **Page** | `pages/` | 데이터 페칭 + 4-pane 조립 | `NotesPage` |

> 💡 **규칙**: 상위 계층은 하위만 import. UI Primitives는 외부 의존 0.

**🇺🇸 English**

### 1.1 Component Classification (Atomic Design variant)

| Layer | Location | Responsibility | Examples |
|---|---|---|---|
| **UI Primitives** | `components/ui/` | Atomic reusable components | `Button`, `Input`, `Modal` |
| **Composite** | `components/` | Combine multiple primitives | `NoteCard`, `FolderTree` |
| **Feature** | `features/<domain>/` | Domain logic + state coupling | `TiptapEditor`, `GraphCanvas` |
| **Page** | `pages/` | Data fetching + 4-pane assembly | `NotesPage` |

> 💡 **Rule**: Higher layers only import from lower layers. UI Primitives have zero external dependencies.

### 1.2 상태 관리 전략

| 종류 | 도구 | 우리 사례 |
|---|---|---|
| **서버 상태** (fetch/REST) | **fetch + useEffect** | 노트 목록, 그래프 데이터, 자주 쓴 태그, 캘린더 |
| **전역 클라이언트 상태** | **React Context** | 인증 사용자, **멀티탭**, 현재 폴더, 테마, 모드(파일/그래프) |
| **폼 상태** | **react-hook-form + zod** | 로그인·회원가입·노트 메타 |
| **로컬 UI 상태** | `useState` | 드롭다운 열림, 호버, 토글 |

> 🚫 **금지**: 서버 상태를 Context에 저장 X (캐시 무효화 지옥). fetch + 로컬 state가 캐시 담당.

**🇺🇸 English**

### 1.2 State Management Strategy

| Type | Tool | Our Usage |
|---|---|---|
| **Server state** (fetch/REST) | **fetch + useEffect** | Note list, graph data, top tokens, calendar |
| **Global client state** | **React Context** | Authenticated user, **multi-tab**, current folder, theme, mode (files/graph) |
| **Form state** | **react-hook-form + zod** | Login, signup, note metadata |
| **Local UI state** | `useState` | Dropdown open, hover, toggle |

> 🚫 **Forbidden**: Do not store server state in Context (cache invalidation hell). fetch + local state owns caching.

### 4.3 FolderTree (재귀 컴포넌트)

```typescript
type FolderTreeProps = { tree: FolderNode[] };

type FolderNode = {
  id: string;
  name: string;
  parent_id: string | null;
  order: number;
  children: FolderNode[];
};

function FolderTree({ tree }: FolderTreeProps) {
  return (
    <ul>
      {tree.map((node) => (
        <FolderTreeItem key={node.id} node={node}/>
      ))}
    </ul>
  );
}

function FolderTreeItem({ node }: { node: FolderNode }) {
  const [expanded, setExpanded] = useState(true);
  const [notes, setNotes] = useState<Note[]>([]);

  useEffect(() => {
    if (expanded) {
      notesApi.list({ folder_id: node.id }).then((res) => setNotes(res.items));
    }
  }, [expanded, node.id]);

  return (
    <li>
      <div className="flex cursor-pointer" onClick={() => setExpanded(!expanded)}>
        {expanded ? '▾' : '▸'} 📁 {node.name}
      </div>
      {expanded && (
        <ul className="ml-4">
          {notes.map((n) => <NoteItem key={n.id} note={n}/>)}
          {node.children.map((child) => <FolderTreeItem key={child.id} node={child}/>)}
        </ul>
      )}
    </li>
  );
}
```

### 4.3 FolderTree (recursive component)

### 5.1 TiptapEditor — Tiptap 에디터 + #@& 배지 + 표 (FE1, v2 핵심)

### 5.1 TiptapEditor — Tiptap editor + #@& badges + tables (FE1, v2 core)

#### 5.1.1 TokenBadge 확장 (`#@&` 인라인 노드)

```typescript
// features/editor/extensions/TokenBadge.ts
import { Node, mergeAttributes } from '@tiptap/core';

export const TokenBadge = Node.create({
  name: 'tokenBadge',
  group: 'inline',
  inline: true,
  atom: true,
  addAttributes() {
    return {
      type: { default: 'tag' },   // 'mention' | 'tag' | 'object'
      label: { default: '' },
    };
  },
  parseHTML() {
    return [{ tag: 'span[data-token-badge]' }];
  },
  renderHTML({ HTMLAttributes }) {
    const colors = { mention: 'bg-blue-100 text-blue-700', tag: 'bg-emerald-100 text-emerald-700', object: 'bg-red-100 text-red-700' };
    const prefix = { mention: '@', tag: '#', object: '&' };
    return [
      'span',
      mergeAttributes(HTMLAttributes, {
        'data-token-badge': '',
        class: `rounded px-1 ${colors[HTMLAttributes.type]}`,
      }),
      `${prefix[HTMLAttributes.type]}${HTMLAttributes.label}`,
    ];
  },
});
```

**🇺🇸 English**

#### 5.1.1 TokenBadge extension (`#@&` inline node)

Custom Tiptap inline node that renders colored badge chips. `mention` (@) → blue, `tag` (#) → emerald, `object` (&) → red. Stored as atomic nodes so they cannot be partially edited.

#### 5.1.2 useAutosave 훅 (모든 탭 실시간 저장)

```typescript
// hooks/useAutosave.ts
import { useEffect, useRef } from 'react';
import { useDebounce } from './useDebounce';
import { notesApi } from '@/lib/api/notes';
import { useTabContext } from '@/context/TabContext';

export function useAutosave(noteId: string, editor: Editor | null) {
  const { setSaveState } = useTabContext();
  const content = editor?.storage.markdown.getMarkdown() ?? '';
  const debouncedContent = useDebounce(content, 2000);

  useEffect(() => {
    if (!editor || debouncedContent === '') return;
    setSaveState(noteId, 'saving');
    notesApi.update(noteId, { content: debouncedContent })
      .then(() => setSaveState(noteId, 'saved'))
      .catch(() => setSaveState(noteId, 'error'));
  }, [debouncedContent, noteId, editor]);

  // 페이지 종료 / 탭 닫기 시 즉시 flush
  useEffect(() => {
    const handler = (e: BeforeUnloadEvent) => {
      if (content !== debouncedContent) {
        notesApi.update(noteId, { content });   // 동기 호출 (best effort)
      }
    };
    window.addEventListener('beforeunload', handler);
    return () => window.removeEventListener('beforeunload', handler);
  }, [noteId, content, debouncedContent]);
}
```

**🇺🇸 English**

#### 5.1.2 useAutosave hook (real-time save for all tabs)

Debounces editor content (2 s), then PATCHes via REST. Reports `saving` / `saved` / `error` save states to `TabContext`. On `beforeunload`, flushes unsaved content immediately (best-effort synchronous call).

#### 5.1.3 useAutocomplete 훅 (Tiptap suggestion + tippy.js)

```typescript
// hooks/useAutocomplete.ts
export function useAutocomplete() {
  return {
    char: ['@', '#', '&'],   // 트리거 문자
    allowSpaces: false,
    startOfLine: false,
    items: async ({ query, char }) => {
      const type = char === '@' ? 'mention' : char === '#' ? 'tag' : 'object';
      // 캐시에서 기존 토큰 필터링
      const matched = filterTokensByType(type, query);
      return [...matched, { isNew: true, label: query }];   // "+ 새로 만들기"
    },
    render: () => {
      // tippy.js 드롭다운 렌더링 (별도 컴포넌트)
    },
  };
}
```

**🇺🇸 English**

#### 5.1.3 useAutocomplete hook (Tiptap suggestion + tippy.js)

Returns a Tiptap suggestion config. Triggered by `@`, `#`, `&`. Filters existing tokens from local cache and always appends a "+ Create new" entry. The dropdown UI is rendered with tippy.js.

### 6.2 Tab Context ⭐ v2 신규 (멀티탭 핵심)

```typescript
// context/TabContext.tsx
type Tab = {
  id: string;           // noteId
  title: string;
  saveState: 'idle' | 'saving' | 'saved' | 'error';
};

type TabContextValue = {
  tabs: Tab[];
  activeTabId: string | null;
  open: (noteId: string) => void;       // 이미 있으면 활성화, 없으면 추가
  activate: (tabId: string) => void;
  close: (tabId: string) => void;       // 자동저장 flush 후 닫기
  setSaveState: (tabId: string, state: Tab['saveState']) => void;
  hydrate: () => void;                  // localStorage 복원
};

export function TabProvider({ children }: { children: React.ReactNode }) {
  const [tabs, setTabs] = useState<Tab[]>([]);
  const [activeTabId, setActiveTabId] = useState<string | null>(null);

  const open = (noteId: string) => {
    const existing = tabs.find((t) => t.id === noteId);
    if (existing) {
      setActiveTabId(noteId);
    } else {
      const newTab: Tab = { id: noteId, title: '...', saveState: 'idle' };
      setTabs((prev) => {
        const next = [...prev, newTab];
        persistTabs(next);
        return next;
      });
      setActiveTabId(noteId);
    }
  };

  const activate = (tabId: string) => setActiveTabId(tabId);

  const close = (tabId: string) => {
    setTabs((prev) => {
      const next = prev.filter((t) => t.id !== tabId);
      persistTabs(next);
      return next;
    });
    setActiveTabId((cur) => cur === tabId ? (tabs[tabs.length - 2]?.id ?? null) : cur);
  };

  const setSaveState = (tabId: string, state: Tab['saveState']) =>
    setTabs((prev) => prev.map((t) => t.id === tabId ? { ...t, saveState: state } : t));

  const hydrate = () => {
    const saved: Tab[] = JSON.parse(localStorage.getItem('tabs') ?? '[]');
    setTabs(saved);
    setActiveTabId(saved[0]?.id ?? null);
  };

  return (
    <TabContext.Provider value={{ tabs, activeTabId, open, activate, close, setSaveState, hydrate }}>
      {children}
    </TabContext.Provider>
  );
}

function persistTabs(tabs: Tab[]) {
  localStorage.setItem('tabs', JSON.stringify(tabs.map(({ id, title }) => ({ id, title }))));
}
```

**🇺🇸 English**

### 6.2 Tab Context ⭐ v2 new (multi-tab core)

`TabProvider` manages the list of open editor tabs and which tab is active. Tab state persists to `localStorage` so it survives page refresh (`hydrate` restores on app boot). `open` is idempotent — if the note is already open it just activates that tab.
