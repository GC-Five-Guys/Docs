## 1. 설계 철학

### 1.1 컴포넌트 분류 (Atomic Design 변형)

| 계층 | 위치 | 책임 | 예시 |
|---|---|---|---|
| **UI Primitives** | `components/ui/` | 디자인 시스템의 원자 (재사용) | `Button`, `Input`, `Modal` |
| **Composite** | `components/` | 여러 primitive 조합 | `NoteCard`, `Sidebar` |
| **Feature** | `features/<domain>/` | 도메인 로직 + 상태 결합 | `NoteEditor`, `GraphCanvas` |
| **Page** | `app/**/page.tsx` | 데이터 페칭 + 레이아웃 | `NotesPage` |

> 💡 **규칙**: 상위 계층은 하위만 import. UI Primitives는 외부 의존 0.

### 1.2 상태 관리 전략

| 종류 | 도구 | 예시 |
|---|---|---|
| **서버 상태** (캐시·revalidation) | **SWR** | 노트 목록, 그래프 데이터 |
| **전역 클라이언트 상태** | **Zustand** | 인증 사용자, 현재 폴더, 테마 |
| **폼 상태** | **react-hook-form** | 로그인·회원가입·노트 메타 |
| **로컬 UI 상태** | `useState` | 드롭다운 열림, 호버, 토글 |

> 🚫 **금지**: 서버 상태를 Zustand에 저장하지 않음 (캐시 무효화 지옥). SWR이 캐시·동기화 담당.

## 5. Feature 컴포넌트 (핵심)

### 5.1 NoteEditor (FE1 담당)

> 가장 복잡한 컴포넌트. 자동저장 + 자동완성 + 링크 파싱 미리보기.

```typescript
// features/editor/NoteEditor.tsx
type NoteEditorProps = {
  noteId: string;
  initialContent: string;
};

function NoteEditor({ noteId, initialContent }: NoteEditorProps) {
  const [content, setContent] = useState(initialContent);
  const [saveState, setSaveState] = useState<'idle' | 'saving' | 'saved' | 'error'>('idle');
  const debouncedContent = useDebounce(content, 2000);

  // 자동저장
  useEffect(() => {
    if (debouncedContent === initialContent) return;
    setSaveState('saving');
    notesApi.update(noteId, { content: debouncedContent })
      .then(() => setSaveState('saved'))
      .catch(() => setSaveState('error'));
  }, [debouncedContent, noteId, initialContent]);

  // 자동완성
  const { triggerType, query, position, suggestions, isOpen } = useAutocomplete(content);

  return (
    <div className="grid grid-cols-2 gap-4 h-full">
      <MarkdownEditor
        value={content}
        onChange={setContent}
        onAutocompleteTrigger={(type, query, pos) => { /* ... */ }}
      />
      <MarkdownPreview content={content}/>
      {isOpen && (
        <AutocompleteDropdown
          type={triggerType}
          query={query}
          position={position}
          suggestions={suggestions}
          onSelect={(value) => insertAtCursor(value)}
        />
      )}
      <SaveIndicator state={saveState}/>
    </div>
  );
}
```

#### 5.1.1 자동완성 훅

```typescript
// hooks/useAutocomplete.ts
type TriggerType = 'mention' | 'tag' | 'pac';

function useAutocomplete(content: string) {
  // 1. 현재 커서 위치에서 마지막 @ / # / & 감지
  // 2. 트리거 후 입력된 query 추출
  // 3. type별로 API 호출 or 정적 옵션 제공
  //    - mention: GET /notes (자주 사용된 mention들 from cache)
  //    - tag: GET /notes (자주 쓴 tag 목록)
  //    - pac: ['Parent', 'Adult', 'Child'] 고정
  return { triggerType, query, position, suggestions, isOpen };
}
```

### 5.2 GraphCanvas (FE1 담당)

```typescript
// features/graph/GraphCanvas.tsx
import ForceGraph3D from 'react-force-graph-3d';

type GraphCanvasProps = {
  data: {
    nodes: GraphNode[];
    links: GraphLink[];
  };
  onNodeClick: (node: GraphNode) => void;
  onNodeDoubleClick: (node: GraphNode) => void;
  highlightedNodeIds?: string[];
};

function GraphCanvas({ data, onNodeClick, onNodeDoubleClick, highlightedNodeIds }: GraphCanvasProps) {
  const fgRef = useRef<any>();

  // 노드 클릭 시 카메라 포커스
  const handleNodeClick = useCallback((node: any) => {
    const distance = 40;
    const distRatio = 1 + distance / Math.hypot(node.x, node.y, node.z);
    fgRef.current.cameraPosition(
      { x: node.x * distRatio, y: node.y * distRatio, z: node.z * distRatio },
      node,
      1000
    );
    onNodeClick(node);
  }, [onNodeClick]);

  return (
    <ForceGraph3D
      ref={fgRef}
      graphData={data}
      nodeLabel="label"
      nodeColor={(n: any) => n.color}
      nodeVal={(n: any) => n.size}
      linkColor={(l: any) => '#888'}
      linkWidth={(l: any) => Math.sqrt(l.weight)}
      onNodeClick={handleNodeClick}
      onNodeRightClick={onNodeDoubleClick}
    />
  );
}
```

#### 핵심 의존성

- `react-force-graph-3d` (v1.24+) — Three.js 래퍼, force 시뮬레이션 내장
- `three` (v0.164+) — 직접 import 안 해도 됨 (의존성으로 자동 설치)

'use client';

function GraphPage() {
  const [tab, setTab] = useState<'mention' | 'tag' | 'pac'>('mention');
  const { data, error, isLoading } = useSWR(
    `/graph?type=${tab}`,

  return (
    <div className="h-full flex flex-col">
      <GraphTabs value={tab} onChange={setTab}/>
      {isLoading && <Spinner/>}
      {error && <ErrorState onRetry={() => mutate()}/>}
      {data && (
        <GraphCanvas
          data={data}
          onNodeClick={setSelectedNode}
          onNodeDoubleClick={(n) => router.push(`/notes/${n.doc_id}`)}
        />
      )}
      <GraphFilters/>
      <Legend/>
      <GraphStats data={data}/>
      {selectedNode && (
        <NodePreviewPopup
          node={selectedNode}
          onClose={() => setSelectedNode(null)}
        />
      )}
    </div>
  );
}

```typescript
// store/authStore.ts
type AuthState = {
  user: User | null;
  token: string | null;
  login: (user: User, token: string) => void;
  logout: () => void;
  isAuthenticated: () => boolean;
};

export const useAuthStore = create<AuthState>((set, get) => ({
  user: null,
  token: typeof window !== 'undefined' ? localStorage.getItem('token') : null,
  login: (user, token) => {
    localStorage.setItem('token', token);
    set({ user, token });
  },
  logout: () => {
    localStorage.removeItem('token');
    set({ user: null, token: null });
  },
  isAuthenticated: () => !!get().token,
}));
```

## 8. API 클라이언트

```typescript
// lib/api/client.ts
import axios from 'axios';
import { useAuthStore } from '@/store/authStore';

export const axiosClient = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_BASE_URL,
  timeout: 10000,
});

// 요청 인터셉터: JWT 자동 첨부
axiosClient.interceptors.request.use((config) => {
  const token = useAuthStore.getState().token;
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// 응답 인터셉터: 401 → 로그아웃
axiosClient.interceptors.response.use(
  (res) => res.data.data,  // { success, data } 에서 data만 추출
  (error) => {
    if (error.response?.status === 401) {
      useAuthStore.getState().logout();
      window.location.href = '/login';
    }
    return Promise.reject(error.response?.data?.error ?? error);
  }
);
```

```typescript
// lib/api/notes.ts
export const notesApi = {
  list: (params?: { folder_id?: string; page?: number }) => axiosClient.get('/notes', { params }),
  get: (id: string) => axiosClient.get(`/notes/${id}`),
  create: (data: { title: string; content: string; folder_id?: string }) => axiosClient.post('/notes', data),
  update: (id: string, data: { title?: string; content?: string }) => axiosClient.put(`/notes/${id}`, data),
  remove: (id: string) => axiosClient.delete(`/notes/${id}`),
  search: (q: string) => axiosClient.get('/notes/search', { params: { q } }),
};

// lib/api/graph.ts
export const graphApi = {
  get: (params: { type: 'mention' | 'tag' | 'pac' }) => axiosClient.get('/graph', { params }),
  getNode: (label: string) => axiosClient.get(`/graph/node/${encodeURIComponent(label)}`),
};
```
