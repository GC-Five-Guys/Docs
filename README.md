## 1. 이 문서 패키지를 읽는 순서

처음 오신 분(교수님·신규 팀원·외부 검토자)은 다음 순서로 보시면 **5분 안에 전체 그림**이 잡힙니다.

```
1) 본 README                                "전체 그림 + 변경 이력"
   ↓
2) 프로젝트 기획서 (01_기획/)                  "무엇을 / 왜 만드는가?"
   ↓
3) WBS + 일정 (02_일정/)                      "누가 / 언제까지 / 무엇을?"
   ↓
4) 시스템 아키텍처 (03_설계/)                  "어떻게 작동하는가?"
   ↓
5) DB · API · UI · 컴포넌트 설계 (03_설계/)    역할별 깊이 있게
   ↓
6) 개발 가이드 (04_개발가이드/)                "어떻게 협업하는가?"
   ↓
7) 회의록 + 리스크 (05_관리/)                  "어떻게 관리되는가?"
```

## 2. 한눈에 보기 (1분 요약)

### 우리가 만드는 것

> **한국 학생을 위한 일기 도구.**
> `#주제` `@인물` `&오브젝트` 3가지 태그를 일기에 자유롭게 적고, **자동 클러스터링되는 2D 그래프**로 자기 자신을 패턴으로 본다.

### 4-pane 화면 미리보기

```

│📁│ 일기     │ [노트1 ▼] [노트2 ×]   │ 🔍 검색      │
│🌐│ ├ 2026   │ # 오늘 일기            │ 🏷 자주 쓴   │
```

## 7. 자주 묻는 질문 (FAQ)

### Q. 왜 Notion/Obsidian 안 쓰고 직접 만드나요?

**A.** Notion은 일기에 너무 무겁고, Obsidian은 한국 학생에게 너무 어렵습니다. 우리는 **한국 학생이 부담 없이 시작하고 시간이 지나면 자기 자신을 패턴으로 볼 수 있는** 일기 도구를 만듭니다.

### Q. 차별점이 정말 있나요?

**A.** 솔직히 비슷한 도구는 많습니다. 하지만 **3가지 의미별 태그(`#@&`) + 자동 클러스터링 그래프 + 한국어 일기 워크플로우**의 조합은 시중에 없습니다. 또한 학기 프로젝트의 학습 목표는 "차별성"보다 "**라이브러리를 조합해 가치를 만드는 능력**"입니다.

### Q. 4주에 가능한가요?

**A.** Must Have 12개로 MVP를 정의했습니다. Tiptap·2D 그래프·우측바는 W3에 집중하고, W1·W2는 그 발판입니다. 리스크 대장에서 일정 리스크 6개를 별도 추적합니다.

### Q. 가장 어려운 부분은?

**A.** **Tiptap (ProseMirror) 학습 + 2D 그래프 자동 클러스터링 + 멀티탭 + 우측바** 4가지가 무겁습니다. FE1·FE2·BE1에 분산하고, W1부터 사전 학습/PoC를 진행합니다.

### Q. v1과 v2 차이는?

**A.** 2026-05-23 기획 재정의. 메인 목적을 "자기 성찰 PKM (PAC)"에서 "**한국 학생용 일기 도구**"로 좁히고, 3D 그래프 → 2D, `&` PAC → 자유 형식 오브젝트, 3-pane → 4-pane으로 변경했습니다. 상세는 §10 변경 이력 참고.

### v1 → v2 변경 누적 (상세)

| 영역 | v1 | v2 | 영향 |
|---|---|---|---|
| **메인 목적** | 자기 성찰 PKM (PAC 중심) | **한국 학생용 일기 도구** | 모든 페르소나·시나리오 재작성 |
| **`&` 의미** | PAC (Parent/Adult/Child) | **자유 형식 오브젝트** | DB·파서·UI 단순화 |
| **그래프** | 3D + 타입별 분리 3개 (탭) | **2D + 파일 중심 + 자동 공통토큰 엣지 + 토글** | FE1 학습 -2일 |
| **에디터** | `@uiw/react-md-editor` | **Tiptap (ProseMirror)** | FE1 학습 +2일, 표 GUI + 배지 가능 |
| **레이아웃** | 3-pane | **4-pane** (메뉴/파일목록/메인/우측바) | FE2 컴포넌트 +5개 |
| **멀티탭** | 없음 | **무제한 + 실시간 자동저장** | 상태 관리 추가 |
| **우측바** | 없음 | **검색 + 자주 쓴 태그 9개 + 월간 캘린더** | API +3개 |
| **검색** | 단순 키워드 | **통합 (엔티티 + 노트)** | API 재정의 |
| **삭제** | (정의 없음) | **하드 삭제 + 확인 모달** | 휴지통 UI 폐기 |
| **자동완성** | 즉시 트리거 | **공백 다음에만** | 이메일 false-positive 방지 |
| **노드 클릭** | 단일 클릭 | **호버 카드 + 더블클릭** | 실수 방지 |
