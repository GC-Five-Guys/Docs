   ↓

## 2. 한눈에 보기 (1분 요약)

### 우리가 만드는 것

> 개인의 생각·인물·관계를 **@(언급) / #(해시태그) / &(PAC 관계)** 세 가지 의미별 링크로 연결하고, 각 링크 타입을 **분리된 3D 그래프**로 시각화하는 **개인 지식 관리 웹 서비스**.

### 차별점

| Notion | Obsidian | Roam | **Tri-Link (우리)** |
|:---:|:---:|:---:|:---:|
| 마크다운 + DB | 마크다운 + 2D 그래프 | 마크다운 + 2D 그래프 | **마크다운 + 의미별 3D 그래프 (3개) + PAC 자기 성찰** |

## 7. 자주 묻는 질문 (FAQ)

### Q. 왜 Notion/Obsidian이 있는데 이걸 만드나요?

**A.** 기존 도구는 "링크"가 모두 한 종류입니다. 우리는 @(누구), #(무엇), &(어떤 상태)를 의미적으로 분리해서, 같은 데이터에서 **세 가지 다른 통찰**을 줍니다. 특히 **PAC(Parent/Adult/Child) 관계 분석**은 자기 성찰을 위한 시각화 도구로서 어디에도 없습니다.

### Q. 4주에 가능한가요?

**A.** Must Have 7개만으로 MVP를 정의했습니다. 3D 그래프와 에디터는 W3에 집중하고, W1·W2는 그 발판을 만드는 데만 씁니다. 리스크 대장에서 일정 리스크 5개를 별도 추적합니다.

### Q. 가장 어려운 부분은?

**A.** **3D 그래프 렌더링 + 자동저장 에디터 + 자동완성** 3가지가 가장 무겁습니다. FE1에게 전담시키고, FE2가 디자인·인증·반응형으로 보조합니다.

### Q. 외부 라이브러리에 너무 의존하는 거 아닌가요?

**A.** 학기 프로젝트의 학습 목표는 "**라이브러리를 어떻게 조합해 가치를 만드는가**" 입니다. 핵심 비즈니스 로직(링크 파서, 그래프 데이터 추출, PAC 관계 모델링)은 직접 작성합니다.
