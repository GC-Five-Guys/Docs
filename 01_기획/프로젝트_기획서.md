## 1. 왜 이 프로젝트를 하는가? (Why)

### 1.1 문제 정의

> **"한국 학생들은 일기를 쓰고 싶어도 도구가 어렵거나 가벼움이 부족하다."**

| 도구 | 학생이 일기 도구로 쓸 때 문제 |
|---|---|
| **종이 일기장** | 검색 불가, 잃어버리기 쉬움, 패턴 발견 불가 |
| **Apple Notes / 네이버 메모** | 태그·관계 표현 불가, 단순 메모 수준 |
| **Notion** | 페이지 단위가 무거움, 일기를 위해 데이터베이스 만들기 부담, 한국어 검색 약함 |
| **Obsidian** | 영어권 위주, 그래프가 너무 복잡, 마크다운 학습 곡선, 일기 워크플로우 약함 |
| **Day One / Diarium (유료)** | 한국에서 안 쓰임, 가격, 한국어 폰트 어색 |

→ **공백**: "**한국 학생이 부담 없이 시작하고, 시간이 지나면 자기 자신을 패턴으로 볼 수 있는** 일기 웹 도구"가 없음.

### 1.2 우리의 가설

일기에 등장하는 모든 단어 중 **세 가지만 태그**로 분리하면 자기 인식이 폭증한다.

| 태그 | 의미 | 예시 | 답해주는 질문 |
|---|---|---|---|
| `#주제` | 그날의 상태/감정/맥락 | `#감정조절` `#시험` `#여행` | "최근 내가 몰입한 주제는?" |
| `@인물` | 등장한 사람 | `@엄마` `@동기A` `@교수님` | "최근 내 삶의 중심 인물은?" |
| `&오브젝트` | 사물·도구·콘텐츠·이벤트 (자유 형식) | `&커피` `&개발자북` `&할머니생신` | "내가 가장 자주 마주하는 것은?" |

이 셋을 1주만 꾸준히 적으면 **그래프에 자기 자신의 패턴이 자동으로 드러난다.**

### 1.3 시장 기회 & 차별점

| 기능 | Notion | Obsidian | Diarium | **Tri-Link (우리)** |
|---|:---:|:---:|:---:|:---:|
| 일기 작성 | △ | △ | ✅ | ✅ |
| 한국어 친화 (UI/검색/폰트) | △ | △ | ❌ | ✅ |
| 의미별 태그 분리 (`#@&`) | ❌ | ❌ | ❌ | ✅ |
| 자동 그래프 시각화 | ❌ | ✅ | ❌ | ✅ |
| **자동 공통태그 클러스터링** | ❌ | △ (수동 링크 필요) | ❌ | ✅ |
| 일기에 특화된 우측바 (캘린더+태그) | ❌ | ❌ | ✅ | ✅ |
| 가격 | 부분 무료 | 무료 (개인) | 유료 | **무료 (학기 시연)** |

## 2. 무엇을 만드는가? (What)

### 2.1 핵심 솔루션 — 4-pane 일기 워크스페이스

```
┌──┬──────────┬──────────────────────────┬──────────────┐
│📁│ 일기     │ [노트1 ▼] [노트2 ×]       │ 🔍 검색      │
│🌐│ ├ 2026   │ ────────────────────     │              │
│  │ │ └ 5월  │ # 오늘 일기               │ 🏷 자주 쓴   │
│  │ 📁 회의   │ [@엄마] 와 통화함.        │ 태그 (3타입)  │
│  │          │ [#감정조절] 실패.          │              │
│  │ + 새파일 │ [&독서] 안 함.             │ 📅 캘린더     │
│  │ + 새폴더 │                            │ (월간 + dot) │
│  │          │ 표는 Obsidian 스타일      │              │
└──┴──────────┴──────────────────────────┴──────────────┘
   ↑      ↑              ↑                     ↑
   메뉴   파일목록바       메인 (멀티탭 + Tiptap)  우측바
   60px   240px           가변                   300px
```

## 3. 누가 사용하는가? (Who)

### 3.1 핵심 페르소나

#### 페르소나 ①: "꾸준한 일기를 시도하는 대학생, 지수"
- **나이/직업**: 21세, 가천대학교 심리학과 2학년
- **상황**:
  - 시험 기간마다 스트레스로 무너짐, 패턴이 반복되는 느낌
  - 종이 일기는 3일 만에 포기, Notion은 너무 무거움
- **니즈**: "오늘 있었던 일을 빠르게 적되, 나중에 패턴이 보였으면 좋겠다"
- **Tri-Link 사용법**:
  1. 매일 자기 전 1-2개 노트 작성 (멀티탭)
  2. `오늘 #시험준비 실패. @동기A 와 #감정조절 얘기. &에너지드링크 너무 많이 마심.`
  3. 한 달 뒤 그래프 뷰 진입 → `&에너지드링크`가 `#불안`과 자주 함께 등장하는 패턴 발견
  4. "에너지드링크를 줄여야겠다" 같은 작은 깨달음 → 일기를 계속 쓰는 동기

#### 페르소나 ②: "여행/취미 기록을 쌓는 직장인, 민호"
- **나이/직업**: 28세, IT 직장인
- **상황**: 여행·독서·요리 기록을 분산 저장 중 (Notion, Instagram, 일기장)
- **니즈**: "한 곳에서 빠르게 적고, 나중에 카테고리별로 보고 싶다"
- **Tri-Link 사용법**:
  - `5/19 제주 여행. @동생 과 갔다. #여행 #제주 &협재해수욕장 &흑돼지`
  - "&" 그래프 토글 → 가본 장소·먹은 음식이 자동으로 모임
  - 우측바 캘린더에서 여행 날짜만 골라 다시 보기

### 3.2 사용 시나리오 (Day in the Life — 지수)

```mermaid

    title 지수의 하루 — Tri-Link 사용 흐름

    section 점심 (3분)

    section 주말 (15분)

```

## 4. 어떻게 성공을 측정하는가? (KPI)

### 4.1 1차 KPI (학기말 시연용 목표)

| 지표 | 목표 | 측정 방법 |
|---|---|---|
| **MVP 완성도** | Must Have 12개 기능 100% 동작 | 시연 영상 + GitHub README |
| **외부 테스트 사용자** | 팀원 외 **10명 이상** | `users` 컬렉션 카운트 |
| **사용자당 노트 수** | 평균 **5개 이상** | `documents` 집계 |
| **그래프 뷰 진입률** | 노트 작성자 중 **70%+** | 페이지 이벤트 |
| **3가지 태그 모두 사용** | 사용자의 **30%+** | 노트 파싱 집계 |
| **재방문율 (3일 이내)** | **40%+** | 로그인 이벤트 |

### 4.2 2차 KPI (서비스화 시)

- MAU / WAU / 평균 세션 시간
- 태그 타입별 사용 분포 (`#:@:&` 비율)
- 캘린더 / 우측바 / 그래프 진입률
- 사용자 만족도 (NPS)
