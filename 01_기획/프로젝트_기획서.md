## 1. 왜 이 프로젝트를 하는가? (Why)

### 1.1 문제 정의

> **"한국 학생들은 일기를 쓰고 싶어도 도구가 어렵거나 가벼움이 부족하다."**

| 도구 | 학생이 일기 도구로 쓸 때 문제 |
|---|---|
| **종이 일기장** | 검색 불가, 잃어버리기 쉬움, 패턴 발견 불가 |
| **Apple Notes / 네이버 메모** | 태그·관계 표현 불가, 단순 메모 수준 |
| **Notion** | 페이지 단위가 무거움, 일기를 위해 데이터베이스 만들기 부담, 한국어 검색 약함 |
| **Obsidian** | 영어권 위주, 그래프가 너무 복잡, 마크다운 학습 곡선, 일기 워크플로우 약함 |
| **Day One / Diarium (유료)** | 한국에서 안 쓰임, 가격, 한국어 폰트 어색 |

→ **공백**: "**한국 학생이 부담 없이 시작하고, 시간이 지나면 자기 자신을 패턴으로 볼 수 있는** 일기 웹 도구"가 없음.

**🇺🇸 English**

### 1.1 Problem Definition

> **"Korean students want to keep a diary, but the tools are either too difficult or not lightweight enough."**

| Tool | Problems when a student uses it as a diary |
|---|---|
| **Paper diary** | Not searchable, easy to lose, no pattern discovery |
| **Apple Notes / Naver Memo** | Cannot express tags or relationships; only basic memos |
| **Notion** | Page units feel heavy, building a database just for a diary is burdensome, weak Korean search |
| **Obsidian** | English-centric, overly complex graph, markdown learning curve, weak diary workflow |
| **Day One / Diarium (paid)** | Not used in Korea, pricing, awkward Korean fonts |

→ **The gap**: There is no diary web tool that lets **a Korean student start without pressure and, over time, see themselves as patterns**.

### 1.2 우리의 가설

일기에 등장하는 모든 단어 중 **세 가지만 태그**로 분리하면 자기 인식이 폭증한다.

| 태그 | 의미 | 예시 | 답해주는 질문 |
|---|---|---|---|
| `#주제` | 그날의 상태/감정/맥락 | `#감정조절` `#시험` `#여행` | "최근 내가 몰입한 주제는?" |
| `@인물` | 등장한 사람 | `@엄마` `@동기A` `@교수님` | "최근 내 삶의 중심 인물은?" |
| `&오브젝트` | 사물·도구·콘텐츠·이벤트 (자유 형식) | `&커피` `&개발자북` `&할머니생신` | "내가 가장 자주 마주하는 것은?" |

이 셋을 1주만 꾸준히 적으면 **그래프에 자기 자신의 패턴이 자동으로 드러난다.**

**🇺🇸 English**

### 1.2 Our Hypothesis

If you separate just **three kinds of words** from everything that appears in a diary as tags, self-awareness grows dramatically.

| Tag | Meaning | Examples | The question it answers |
|---|---|---|---|
| `#topic` | The day's state / emotion / context | `#emotion-control` `#exam` `#travel` | "What topic have I been absorbed in lately?" |
| `@person` | People who appeared | `@mom` `@classmateA` `@professor` | "Who has been central to my life recently?" |
| `&object` | Objects, tools, content, events (free form) | `&coffee` `&dev-book` `&grandma-birthday` | "What do I encounter most often?" |

If you write these three consistently for just one week, **your own patterns automatically surface in the graph.**

## 2. 무엇을 만드는가? (What)

### 2.1 핵심 솔루션 — 4-pane 일기 워크스페이스

```
┌──┬──────────┬──────────────────────────┬──────────────┐
│📁│ 일기     │ [노트1 ▼] [노트2 ×]       │ 🔍 검색      │
│🌐│ ├ 2026   │ ────────────────────     │              │
│  │ │ └ 5월  │ # 오늘 일기               │ 🏷 자주 쓴   │
│  │ 📁 회의   │ [@엄마] 와 통화함.        │ 태그 (3타입)  │
│  │          │ [#감정조절] 실패.          │              │
│  │ + 새파일 │ [&독서] 안 함.             │ 📅 캘린더     │
│  │ + 새폴더 │                            │ (월간 + dot) │
│  │          │ 표는 Obsidian 스타일      │              │
└──┴──────────┴──────────────────────────┴──────────────┘
   ↑      ↑              ↑                     ↑
   메뉴   파일목록바       메인 (멀티탭 + Tiptap)  우측바
   60px   240px           가변                   300px
```

**🇺🇸 English**

### 2.1 Core Solution — A 4-pane Diary Workspace

*Diagram labels (translated):* `메뉴` = Menu (60px), `파일목록바` = File list bar (240px), `메인 (멀티탭 + Tiptap)` = Main area (multi-tab + Tiptap, flexible width), `우측바` = Right sidebar (300px). Inside the panes: `일기` = Diary, `회의` = Meeting, `새파일` = New file, `새폴더` = New folder, `오늘 일기` = Today's diary, `엄마 와 통화함` = Called mom, `감정조절 실패` = Failed at emotion control, `독서 안 함` = Did not read, `검색` = Search, `자주 쓴 태그 (3타입)` = Frequently used tags (3 types), `캘린더 (월간 + dot)` = Calendar (monthly + dots).

## 3. 누가 사용하는가? (Who)

### 3.1 핵심 페르소나

#### 페르소나 ①: "꾸준한 일기를 시도하는 대학생, 지수"
- **나이/직업**: 21세, 가천대학교 심리학과 2학년
- **상황**:
  - 시험 기간마다 스트레스로 무너짐, 패턴이 반복되는 느낌
  - 종이 일기는 3일 만에 포기, Notion은 너무 무거움
- **니즈**: "오늘 있었던 일을 빠르게 적되, 나중에 패턴이 보였으면 좋겠다"
- **Yggdrasil 사용법**:
  1. 매일 자기 전 1-2개 노트 작성 (멀티탭)
  2. `오늘 #시험준비 실패. @동기A 와 #감정조절 얘기. &에너지드링크 너무 많이 마심.`
  3. 한 달 뒤 그래프 뷰 진입 → `&에너지드링크`가 `#불안`과 자주 함께 등장하는 패턴 발견
  4. "에너지드링크를 줄여야겠다" 같은 작은 깨달음 → 일기를 계속 쓰는 동기

#### 페르소나 ②: "여행/취미 기록을 쌓는 직장인, 민호"
- **나이/직업**: 28세, IT 직장인
- **상황**: 여행·독서·요리 기록을 분산 저장 중 (Notion, Instagram, 일기장)
- **니즈**: "한 곳에서 빠르게 적고, 나중에 카테고리별로 보고 싶다"
- **Yggdrasil 사용법**:
  - `5/19 제주 여행. @동생 과 갔다. #여행 #제주 &협재해수욕장 &흑돼지`
  - "&" 그래프 토글 → 가본 장소·먹은 음식이 자동으로 모임
  - 우측바 캘린더에서 여행 날짜만 골라 다시 보기

### 3.1 Core Personas

#### Persona ①: "Jisu, a university student trying to keep a consistent diary"
- **Age/Occupation**: 21, 2nd-year Psychology major at Gachon University
- **Situation**:
  - Breaks down from stress every exam period, feels like the pattern keeps repeating
  - Gives up on a paper diary within 3 days; Notion feels too heavy
- **Needs**: "I want to jot down what happened today quickly, and later be able to see the patterns"
- **How Jisu uses Yggdrasil**:
  1. Writes 1–2 notes before bed every day (multi-tab)
  2. `Today #exam-prep failed. Talked with @classmateA about #emotion-control. Drank way too much &energy-drink.`
  3. A month later, enters the graph view → discovers that `&energy-drink` frequently appears together with `#anxiety`
  4. A small realization like "I should cut down on energy drinks" → motivation to keep journaling

#### Persona ②: "Minho, an office worker accumulating travel/hobby records"
- **Age/Occupation**: 28, IT professional
- **Situation**: Stores travel, reading, and cooking records scattered across places (Notion, Instagram, a diary)
- **Needs**: "I want to write quickly in one place and later view things by category"
- **How Minho uses Yggdrasil**:
  - `5/19 Jeju trip. Went with @younger-sibling. #travel #jeju &Hyeopjae-beach &black-pork`
  - Toggle the "&" graph → places visited and foods eaten automatically cluster
  - Pick only the travel dates from the right-sidebar calendar to revisit
